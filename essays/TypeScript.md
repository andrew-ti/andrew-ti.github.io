TypeScript is a programming language that builds upon the existing JavaScript with features such as static typing. This course has been teaching me TypeScript through various programming exercises that have helped me to understand this language through writing code. As with any programming language, repeated practice is important because many concepts in programming become easier to understand the more you utilize them.

So how exactly does TypeScript differ from its companion? As mentioned before, TypeScript uses static typing, allowing variables/parameters/return types to have specified types. This can help catch mistakes before the program is run, while also making it clearer what kind of data a snippet of code is supposed to utilize. TypeScript is compiled into JavaScript so that it is compatible with JavaScript environments.

Because I was so used to C#, much of TypeScript came naturally to me, but the exact syntax often causes me to make small mistakes (such as typing int i = 0; instead of let i = 0; when creating a for loop). While not much of the content has been new to me so far, practicing using my existing knowledge in new ways is still valuable to me.

The WODs (or exercises, or whatever they are to be referred to as) were my primary source of practice. Because each WOD has a different focus, they allow me to apply everything that I have learned and give me practical experience; just as an athlete must practice their exercise and not just know how it works, so too does a programmer to truly develop their proficiency. As of now, they have involved classes, objects, and arrays, among other things. They also gave me experience with debugging my code and finding what exactly was not working. 

To conclude, TypeScript has been very useful for me to practice my programming skills despite the familiarity of the material. Adjusting to a new environment and its nuances is always a bit of a challenge, even if I already understand most of the concepts. I know now to be more careful with my syntax and am more comfortable in finding and correcting my mistakes. This has all made me more confident in my ability to transfer my programming knowledge between different languages.
